# Rustalgia-EMU

🦀 Rustalgia is an open-source, Rust-powered, multi-console emulator bringing generations of gaming back to life.
Built with a focus on accuracy, performance, modular architecture, and cross-platform support.
Relive the classics, rewritten in Rust. 🎮

## Development

This repository uses [mise](https://mise.jdx.dev/) to install and run its tooling.

- Run `mise install` once.
  It installs every tool and the git hooks.
- Run `mise run check` before pushing.
  It runs everything CI runs.
- Run `mise run fmt` to fix formatting.
