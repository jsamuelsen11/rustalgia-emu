# ---- Added by the source map (R0-05), docs/research/topics/R0-05-source-map.md. ----
# A web address is matched as written: "example.org/wiki" does not match "www.example.org/wiki".
# "none stated" means none on the pages read; the note lists the pages.
# How the guard matches (source-guard.sh states the full rules; changed by issue #32 on 2026-11-27):
# a pattern is plain text, so "~" and "?" are fine, and it matches as a prefix of the address, except that
# "owner/repository" needs a name boundary after it. Closed and tainted web addresses are blocked page and host alike,
# exact address included; a pattern ending in "/" blocks the pages below it but not the page it names.
# Where lines overlap, the longest decides, so an open line can carve a path out of a restricted one.
# A page reached by "index.php?title=" is also matched in its "/wiki/" and "/index.php/" forms.
# Each restricted web pattern has a second line for the www prefix, and archive items a line for their download path.
# Comments below that call a pattern "cut short", or say an "index.php?title=" form cannot be matched, predate #32:
# the cut-short patterns still match by prefix, and those forms are now matched.
