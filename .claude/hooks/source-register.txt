# ---- Added by the source map (R0-05), docs/research/topics/R0-05-source-map.md. ----
# A web address is matched as written: "example.org/wiki" does not match "www.example.org/wiki".
# "none stated" means none on the pages read; the note lists the pages.
# The guard lets through an address that equals a closed or walled pattern exactly, as it does a bare repository page.
# A pattern for one page or one archive item is therefore cut short, so that the full address continues past it.
# Each restricted web pattern has a second line for the www prefix, and archive items a line for their download path.
# A pattern must not hold "~" or "?", which the guard's matching cannot take; a shorter pattern stands in, as noted.
# The address ending in "/" of a closed site's home page is blocked; the address with no "/" passes.
