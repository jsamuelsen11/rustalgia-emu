# Sources that agents may not open, by tier. Decided in docs/adr/0001-restrict-reading-by-licence-tier.md.
# One entry per line: a tier, then a pattern in lower case.
# A pattern is "owner/repository", "owner/" for every repository of an owner, or a web address.
#
# closed:  never opened, except prose files such as the README and the licence.
# walled:  as closed, unless the session was started with RUSTALGIA_SOURCE_ROLE=reader.
# tainted: never opened at all.
